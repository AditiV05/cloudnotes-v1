CloudNotes: Cloud SQL Architecture Design

Cloud SQL for PostgreSQL 17 · db-custom-1-3840 (1 vCPU, 3.75 GB) · region asia-south1 · Regional HA · Private IP only · Secret Manager

🔒 Private connectivity

  • Private IP via Private Services Access 10.10.0.0/16
  • No public IP, no authorized networks
  • Only app-tagged VMs reach tcp:5432 (LU 2.4 firewall)
  • Cloud SQL Auth Proxy: IAM auth + TLS

🔑 Secret Manager + IAM

  • Password in cloudnotes-db-password, versioned and rotatable
  • App SA: cloudsql.client + secretAccessor on that one secret
  • No credentials in git, image or metadata
  • Optional IAM DB auth for humans

💾 Backup strategy

  • Automated daily backups, keep 14
  • Point-in-time recovery, 7 days
  • On-demand backup before every migration
  • Monthly restore drill to a temp instance

🛟 High availability / DR

  • REGIONAL: sync standby in zone b
  • Auto-failover ≈60 s, same IP, RPO ≈ 0
  • Cross-region replica asia-south2 for region loss
  • Rollback: source kept read-only 7 days

💰 Cost (approx., asia-south1)

Single-zone≈ $50–60 / mooutage on zone failure
Regional HA≈ $100–120 / moauto-failover
Devdb-g1-smallzonal, no SLA

📈 vs local deployment

  • Google patches, upgrades and grows storage
  • Backups automatic, not manual pg_dump
  • Survives a zone failure, unlike one laptop
  • Scale by tier change + read replicas
